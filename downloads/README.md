# Baixar MicBridge 0.1.0

- [Android — APK](https://github.com/Erickg246/micbridge/raw/refs/heads/main/downloads/MicBridge-0.1.0-android.apk)
- [Linux Debian/Ubuntu x64 — DEB](https://github.com/Erickg246/micbridge/raw/refs/heads/main/downloads/micbridge_0.1.0_amd64.deb)

No Linux, instale pelo terminal na pasta do arquivo:

```sh
sudo apt install ./micbridge_0.1.0_amd64.deb
```

Abra MicBridge pelo menu de aplicativos. Conecte o Android e o PC à mesma rede Wi-Fi e siga o pareamento mostrado nos apps. Selecione MicBridge_Microfone_do_celular como entrada de áudio no programa Linux.

Versão de teste para Android 8+ e Linux x64. O APK usa chave de depuração. A captura em celular físico ainda precisa de validação.
